# Architecture Rules

## Общие принципы

- Простая понятная архитектура.
- Без лишних абстракций и преждевременного усложнения.
- Каждая сущность и каждый слой имеют свою ответственность.
- Код должен быть легко тестируемым и расширяемым.
- Не дублировать бизнес-логику между компонентами.
- Не создавать абстракции только ради абстракций.

---

## Angular

- Использовать только Standalone Components.
- Не использовать NgModules.
- Компоненты отвечают за отображение и взаимодействие с пользователем.
- Компоненты не должны напрямую обращаться к Supabase.
- Бизнес-логика не должна находиться в HTML-шаблонах.
- Состояние UI хранить с помощью Angular Signals.
- RxJS использовать для асинхронных операций и потоков данных.
- Не использовать `any`.
