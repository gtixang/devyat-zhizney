Тёмная editorial-система «Девять жизней»

Единственный источник истины по визуальному языку продукта — токены и компоненты ниже реализуют docs/design-direction.md и полностью заменяют предыдущую светлую палитру. Структура страниц соответствует схемам из docs/scheme/.

Источник направления: docs/design-direction.md Стилизация: SCSS + БЭМ, Tailwind запрещён Токены — в :root этого файла dss-* классы — только для этой страницы, см. _description.json
01 · Foundations

Цвет

Primary blue — рабочий action-цвет (навигация, процесс, фокус). Magenta accent — единичный эмоциональный акцент (главный CTA, избранное, срочность). Blue и magenta никогда не используются одновременно на одном элементе. Интерфейс остаётся преимущественно тёмным и спокойным: 90% поверхностей — background/surface.

13 · Guidelines

Accessibility

Правила проверяются для каждого нового компонента, а не только на этапе финальной проверки.

  • Контрастtext-primary и text-secondary проверены на AA к background и surface; при недостаточном контрасте мелкого текста — увеличивается кегль, а не цвет вне палитры.
  • Видимый focusЕдиный focus-ring (--focus-ring) на кнопках, полях, ссылках и карточках-ссылках — не убирается без замены.
  • Клавиатурная навигацияВсе интерактивные элементы — реальные <button>/<a>, доступны по Tab в логичном порядке.
  • Читаемый размер текстаБазовый кегль ≥16px в анкетах и каталоге (docs/specs/styles.md), вспомогательный текст не мельче 14px.
  • Touch targetМинимальная высота интерактивных элементов на мобильном — 44px (кнопки, pill-фильтры, пункты мобильного меню — 52–56px).
  • Ошибки формТекст ошибки + смена обводки поля одновременно — цвет никогда не единственный носитель смысла.
  • СтатусыКаждый badge сопровождается текстом состояния, а не только цветом заливки.
  • Alt-текстКаждое фото животного — с содержательным alt (например, «Фото кошки Мурки»).
